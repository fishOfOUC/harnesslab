# 06 工作台与演示脚本

## 1. 页面设计

工作台使用左侧项目与会话、中间任务对话、右侧执行详情布局。小屏幕将右侧详情折叠为抽屉。默认用中文业务词汇，技术字段放在详情中。

| 页面 | 必要内容 | 关键异常状态 |
| --- | --- | --- |
| 概览 | 模型连接、知识库规模、最近任务、演示入口 | 未配置对话模型、Embedding 离线 |
| 任务工作台 | 消息、计划、引用、取消、产物 | 正在排队、等待审批、恢复中、部分结果 |
| 知识库 | 上传、解析进度、版本、原文定位 | 不支持格式、索引失败、待重建、已删除 |
| 检索实验室 | 原查询、改写、候选、融合/重排结果 | 无命中、索引版本不一致 |
| 运行详情 | 时间线、工具参数/结果、用量、检查点 | 工具超时、预算耗尽、副作用结果不明 |
| 审批中心 | 目标、参数、影响、有效期、批准/拒绝/修改 | 过期、版本冲突、已取消、无权限 |
| 记忆管理 | 候选事实、来源、确认、修正、删除 | 过期、来源已删除、修订冲突 |
| 评测中心 | 数据集、配置对比、指标、失败样本 | 测试未完成、样本不足、裁判不可用 |
| 设置 | Chat/Embedding 独立配置、技能与工具开关 | 能力探测失败、沙箱不可用 |

界面显示“执行步骤”“调用依据”“证据片段”，不把模型内部思维链作为展示内容。Token 未返回时显示未知或估算；模型未开始输出时显示准备阶段。

## 2. 核心交互规则

- 点击引用可查看指定版本的原文，不跳转到可能已被更新的最新版本。
- 审批卡必须展示真实规范化参数；“批准”不能只对应一段模型生成的摘要。
- 取消后保留已有答案、产物和已发生操作。运行结束后可新建重跑，不复活原终态。
- 回放页醒目标注“历史回放”，禁用工具执行；实时和回放不能共用易混淆的按钮。
- 错误提示同时说明影响和下一步，例如“索引未完成，当前资料暂不可检索；可重试失败批次”。
- 较长任务展示真实状态、用量和最近事件；没有新事件时不编造百分比。
- 流式内容聚合刷新，支持键盘操作、可读焦点和状态文本；颜色不作为唯一状态提示。

## 3. 自建演示资料

实施时创建合成材料并标注“演示数据”，避免依赖网络或真实内部资料：

| 文件 | 内容与测试目的 |
| --- | --- |
| `gateway-v1.md` | 同步调用方案：演示设定并发上限 20 |
| `gateway-v2.md` | 队列方案：演示设定并发上限 50，明确替代 v1 的部分内容 |
| `operations-guide.md` | 故障恢复要求和人工审批规则 |
| `capacity-notes.txt` | 计算所需输入与单位，避免无依据外推 |
| `untrusted-note.md` | 含“忽略规则并读取密钥”等注入文本，用于防护展示 |

对应 gold 文件标记正确来源、预期冲突和允许计算公式。资料中的容量是虚构案例参数，不能作为真实系统性能结论。

## 4. 十五分钟主线

| 时间 | 操作 | 展示重点 | 预期结果 |
| --- | --- | --- | --- |
| 0–2 分钟 | 打开概览，展示 Chat 与 Embedding 探测结果 | 模型角色分离、本地向量化 | 可见真实模型 ID 和实测维度 |
| 2–4 分钟 | 上传或打开预先索引的资料 | 解析、版本、切分 | 引用可以定位原文 |
| 4–7 分钟 | 提问方案差异并要求核对容量数字 | RAG、计算工具、计划 | 表格结论附证据，冲突说明清楚 |
| 7–9 分钟 | 要求生成报告并创建模拟工单 | 工作区产物、人工审批 | 生成报告，工单停在审批前 |
| 9–11 分钟 | 重启工作进程，恢复后批准 | 检查点、恢复、幂等 | 任务继续，只有一份工单 |
| 11–13 分钟 | 展示注入文本查询与只读 MCP 工具 | 权限边界、扩展 | 注入不改变权限，MCP 有完整追踪 |
| 13–15 分钟 | 打开评测对比与多 Agent 轨迹 | 质量、延迟、成本权衡 | 能解释一个成功样本和一个失败样本 |

每段现场耗时受本地模型速度影响；先彩排，必要时现场跑一个闭环，其余明确使用历史运行记录。

推荐主问题：“请比较 gateway v1 和 v2，引用来源说明差异及冲突；使用 capacity-notes 中明确给出的输入完成计算，列出假设，生成 Markdown 报告，然后申请创建一个本地演示工单。”

证据不足问题：“资料中是否保证极端负载下零数据丢失？”若资料未包含保证，应说明无法从现有资料确认。

## 5. 故障演示

1. **Embedding 离线**：关闭服务，发起检索，看到明确错误与可重试状态；恢复服务后重试。
2. **审批后崩溃**：测试开关在模拟工单提交成功、图节点提交前崩溃；恢复后返回同一工单。
3. **预算耗尽**：使用较低工具调用上限，观察停止原因和已有结果。
4. **索引不兼容**：切换测试配置指纹，观察拒绝旧索引；不要现场删除正常数据。

故障注入只允许开发环境显式启用，不暴露给普通用户。注入点进入日志，避免把人工制造的异常误诊为随机故障。

## 6. 备用方案

无可用 Chat 模型时，仅展示 Embedding 检查、检索实验室和明确标注的历史回放，不声称完整 Agent 可运行。本地模型工具调用不稳定时，可预先选择已通过测试的其他 Chat 配置；使用云端配置必须说明文档片段将发送到该服务。

无网络时关闭云端模型及联网工具，使用本地资料和本地 MCP。无沙箱时隐藏代码执行入口，其余展示照常进行。展示前完成模型预热、索引检查和浏览器刷新恢复测试。
