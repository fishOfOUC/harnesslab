# 01 产品需求与能力矩阵

## 1. 产品目标

构建一个能在单台开发电脑上运行、能解释执行过程、能复现异常恢复的 LangChain 技术展示项目。以“技术资料研究与报告生成”为统一业务场景，让每项工程能力有真实触发条件。

面向三类观众：开发者关注实现机制；技术负责人关注可控性与扩展；普通使用者关注证据可信、可暂停、结果可下载。

验收时分别记录“已实现”“已验证”“受模型限制”“仅规划”。界面不得把预录轨迹展示成实时运行。

## 2. 用户故事

1. 我能上传资料并查看解析、切分、向量化进度；失败时知道是哪份文件出错。
2. 我能基于多份资料提出问题，并点开答案中的引用核对原文。
3. 我能看到任务计划、工具调用、耗时和预算，必要时取消任务。
4. 我能审批即将产生副作用的操作，修改参数后重新确认。
5. 我能在进程重启后恢复等待审批的任务，且不会重复创建工单。
6. 我能比较检索、Prompt 或模型配置改变前后的结果，而不只看一次成功截图。
7. 我能让研究者、核查者和写作者协作，并看到各自输入、工具权限和输出。

## 3. 功能需求与验收映射

优先级：P0 为最小闭环；P1 为完整技术展示；P2 为进阶扩展。需求编号同时用于开发任务、测试用例和演示检查表。

| ID | 能力 | 级别 | 最低验收证据 |
| --- | --- | --- | --- |
| H01 | 模型接入与能力探测 | P0 | Embedding、对话分别探测；缺少工具调用能力时明确提示 |
| H02 | Agent 循环与结构化结果 | P0 | 至少完成一次检索与一次计算，结果通过 Schema 校验 |
| H03 | 会话与短期记忆 | P0 | 同一 thread 连续追问；另一 thread 不串入历史 |

| H05 | RAG 与来源引用 | P0 | 命中原始版本和位置，无资料的问题说明证据不足 |
| H06 | 持久化与恢复 | P0 | 工作进程重启后恢复检查点，副作用结果只产生一份 |
| H07 | 流式事件与取消 | P0 | 重连补齐事件；取消后不再发起新工具调用 |

| H17 | 受限文件工作区与产物 | P1 | 报告可下载；越界路径、符号链接绕过被阻止 |
| H18 | 多 Agent 协作 | P1 | 子任务权限、预算和输出隔离，父任务可汇总或取消 |
| H19 | 权限、注入防护与审计 | P0→P1 | P0 有项目隔离和禁用危险工具；P1 完成对抗测试 |
| H20 | 回放、评测比较与版本追踪 | P1 | 回放不产生副作用；比较页关联数据集和配置快照 |

## 4. 端到端场景

### 场景 A：有证据的技术问答

导入 UTF-8 Markdown、TXT 和带文本层 PDF；提问涉及两份文档的方案差异。输出必须包含结论、证据、冲突点、未知项。只支持文本解析时，扫描 PDF 要明确显示不支持并建议 OCR 扩展。

### 场景 B：受控行动

生成报告后提出创建模拟工单。先展示目标项目、标题和正文；批准后执行；重复点击批准得到同一工单；拒绝则任务返回已完成报告和未执行操作说明。

### 场景 C：故障恢复

在工具已执行但图节点尚未提交的边界注入崩溃。重启后通过工具操作记录与幂等键查询已有结果，再继续生成最终答案。

### 场景 D：扩展与对比

将一个资料查询工具切换为 MCP 适配版本；研究者检索、核查者复核、写作者生成报告。评测页对比单 Agent 与多 Agent，展示额外延迟及完成质量。

## 5. 非功能目标

| 项目 | 初始目标 | 测量条件 |
| --- | --- | --- |
| 运行创建响应 | p95 < 500 ms | 本机、模型调用异步、单用户，至少 30 次 |
| 首个状态事件 | p95 < 1 s | 服务已启动；不把状态事件当首 Token |
| 首 Token 与端到端耗时 | 记录 p50/p95，不预承诺 | 固定模型、上下文长度、机器配置 |
| 文档范围 | 100 份文本资料、约 1 万 chunk | 首次展示基线；超出后单独压测 |
| 并发 | 默认 1 个活跃主任务、2 个子任务槽位 | 子任务槽位共享模型并发限制 |
| 恢复 | 工作进程恢复后 30 s 内开始续跑 | 存储和模型可用，不包含人工等待 |
| 数据隔离 | 跨项目读取、引用和下载测试全部通过 | 后端注入项目作用域，不信任模型传入 ID |

## 6. 不作为首版承诺

完整企业多租户、任意浏览器自动化、任意宿主 Shell、真实邮件发送、所有文档格式和绝对正确答案不属于首版范围。通用 Harness 没有统一的“所有功能”清单，本项目按执行、上下文、工具、持久化、控制、扩展、观测、评测八个方面建立可检查的覆盖。
