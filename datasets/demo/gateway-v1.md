# 接入网关技术规范 v1

> 演示数据。本文中的容量与性能参数为虚构案例值，不代表任何真实系统结论。

## 1. 定位

本规范描述同步调用型接入网关的设计。网关接受上游请求，同步转发到后端服务，并把响应原样返回。

## 2. 并发与容量

- 单实例并发上限：**20**。
- 超时时间：上游请求 5 秒，后端连接 2 秒。
- 过载策略：直接拒绝并返回 429，不做排队。

## 3. 故障处理

- 后端失败时立即向上游返回错误码，不重试。
- 网关自身不保存请求内容，不提供审计记录。

## 4. 已知限制

1. 突发流量下丢弃比例高，缺少缓冲能力。
2. 无法区分可重试错误与不可重试错误。
3. 无人工审批环节：所有写操作在请求到达后立即执行。
